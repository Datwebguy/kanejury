# Bench: 25 real Kane CLI runs

Run with kane-cli 0.10.8 (headless Chrome) on three public practice sites: the Playwright TodoMVC demo, the-internet.herokuapp.com, and the Swag Labs demo shop. Each case has a known right answer.

- `cases.tsv`: the objective, start URL and claim of every case.
- `results.csv`: Kane's verdict, the vision jury's verdict and votes, credits and seconds for every run.

The write-up with results and the cases worth reading is in [docs/evaluation.md](../docs/evaluation.md).
