# Calibration fixtures
`canary-true.png` and `canary-false.png` are small screenshots rendered in Chrome from hand-written HTML (a pricing box and a checkout box).
Their answers are known by construction: the true one shows $19 at checkout, the false one shows $29. They are test images, **not Kane output**.
KaneJury uses them to check that each juror answers correctly before its vote counts.
